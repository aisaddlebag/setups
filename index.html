Kiln

Kiln: Claude models a 3D game asset and checks every angle · instruktlabs/kiln

Set it up

  1. mkdir kiln-install
  2. cd kiln-install
  3. npm init -y
  4. npm install @instruktlabs/kiln
  5. npx --offline --no -- kiln-init ../my-assets --harness claude
  6. cd ../my-assets
  7. Open Claude Code in my-assets and follow START.md

Two prompts to try

Create a low-poly camping lantern with a carry handle. Review it from several angles, refine any problems, and save the editable source and a GLB.
Build a small timber cabin wall as a reusable asset, check it from every side, fix any gaps, and export a GLB.

Needs Node.js 22 or 24 LTS and npm. Local Kiln is free and account-free; hosted Kiln is invite-only.

blenderwright

blenderwright: Claude animates a space shuttle launch in Blender · HoldMyBeer-gg/blenderwright

Set it up

  1. Install uv, then run: uvx blenderwright
  2. Download the latest addon zip from GitHub Releases
  3. Open Blender 5.2 LTS, go to Edit > Preferences > Get Extensions
  4. Click the dropdown (▾), choose Install from Disk, select the zip, and enable blenderwright
  5. Start the server from the blenderwright panel (N-panel) in Blender
  6. Run: claude mcp add blenderwright -- uvx blenderwright

Two prompts to try

Create a Western style 2-story saloon, the outside is more important than any inside detail.
Model a space shuttle on a launch tower, then animate the launch and render 60 frames.

Needs Blender 5.2 LTS (free). Raw Python (execute_blender_code) is off until you tick Allow raw Python in the N-panel, per session.

claude-obsidian: Claude grows your notes into a knowledge graph · AgriciDaniel/claude-obsidian

Godot AI

Godot AI: Claude Code builds your game inside the Godot editor · hi-godot/godot-ai

Set it up

  1. Install uv (once). macOS/Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Windows PowerShell: irm https://astral.sh/uv/install.ps1 | iex
  2. Install the add-on from Godot's AssetLib tab, or from a GitHub release into your-project/addons/godot_ai/
  3. Enable it: Project > Project Settings > Plugins > Godot AI
  4. In the Godot AI dock, press Configure next to Claude Code (or Configure all). Restart the client if it doesn't notice the change.

Two prompts to try

Create a Camera3D named MainCamera under /Main.
Build a voxel block-world game with a player, blocks to place and destroy, and save slots.

Needs Godot 4.7+ and uv. Launch Godot from the project directory, and approve the server once by running claude inside that project. The cyberpunk HUD demo took about 2 hours. Clips: README · hi-godot/godot-ai.
